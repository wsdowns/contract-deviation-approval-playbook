# Deal profile: Lakeshore Health

| Field | |
|---|---|
| Customer | Lakeshore Health, Inc.; Illinois integrated health care delivery system; 14 hospitals and about 22,000 employees |
| Deal | New customer. Annual fees $1,000,000. Term 3 years. Total contract value $3,000,000. Target signature March 31, 2026, the end of the quarter |
| Strategic or standard | **Strategic.** Would be ACME's first health system and a reference account for the sector |
| Upside | Two sister health systems in the same network have asked for demos; rough value $1,500,000 a year, timing next fiscal year |
| Competition | Two vendors in the final round. ACME is the second choice on price |
| Customer data | Employee and operational data. No protected health information (ACME's standard prohibits it) |
| If we say no | The seller expects Lakeshore to move to the other finalist on any term it calls a requirement |
| Precedent | None known; ACME has not sold to a health system |

## Why the customer says it needs each term

The agreement arrives on Lakeshore's own paper, so the seller must work out what differs from ACME's standard. Lakeshore procurement states that its paper is the starting point for every vendor.
